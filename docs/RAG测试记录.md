## 2026-08-16：优化切片和相关度

### 发现的问题

- FAQ 原来按 `##` 切片，4 个退货问题会合成一大块。
- 向量只编码正文，没有编码问题标题。
- 相似度阈值 `0.35` 偏低，“有没有苹果手机？”会误命中提到手机的退货文档。
- FAQ 跨分类时，分类末尾的问题可能被算到下一个分类。

### 修改内容

- FAQ 改成按每个 `### Q...` 问题切片。
- 每个 FAQ 片段保留父级分类和问题标题。
- 建索引时使用“分类 + 问题标题 + 正文”生成向量。
- 相似度最低阈值从 `0.35` 提高到 `0.50`。
- 增加 FAQ 切片测试，防止分类串掉。
- 脚本改用模块方式运行，避免直接运行文件时找不到 `agent` 包：

```powershell
uv run python -m agent.rag.chunker
uv run python -m agent.rag.indexer
```
