# 2.0 开发计划

## 目标

把 1.0 的电商客服 Agent，改成可以换角色、换知识库、换工具的通用 Agent。

## 主要改造

1. **配置化**
   - Agent 名称
   - 角色和系统提示词
   - 欢迎语
   - 模型参数
   - 知识库路径
   - 启用的工具

2. **提示词独立**
   - 不再把“极客商城”和“小极”写死在代码里。
   - 每个 Agent 使用自己的配置文件。

3. **工具可插拔**
   - 工具统一注册。
   - 配置决定是否启用订单、搜索、RAG 等工具。

4. **知识库上传**
   - 用户上传 Markdown、TXT 或 PDF。
   - 系统自动切片、向量化和建立索引。

5. **多 Agent / 多租户**
   - 不同用户可以拥有自己的 Agent 配置和知识库。
   - 配置、会话和数据相互隔离。

6. **部署和文档**
   - Docker 一键启动。
   - 提供默认配置和配置示例。

## 开发顺序

1. 抽出通用 Agent 配置。
2. 让提示词从配置加载。
3. 让工具按配置启用。
4. 增加知识库上传和重建索引。
5. 增加管理员配置页面。
6. 做通用 Agent 测试和 Docker 测试。

## 当前阶段

先完成第 1 步：创建 Agent 配置模型和默认配置，保证现有电商功能仍能运行。
