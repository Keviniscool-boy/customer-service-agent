## 如何阅读

- 错误率比单纯 RPS 更重要；先解决失败，再追求吞吐量。
- P95 表示 95% 请求不超过该时间，P99 更能反映高峰抖动。
- 基础接口和聊天接口不能直接比较：聊天还包含模型 API 与 WeKnora 延迟。
- 业务场景使用预置 JWT，统计不包含注册和登录准备时间；认证突发单独统计。
- 峰值场景使用更短等待时间，用来观察过载表现，不代表日常稳定容量。
- 这是单机学习环境结果，不代表生产服务器容量。
